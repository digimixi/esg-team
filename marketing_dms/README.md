**💡 【操作指南】如何將這裡的檔案轉為 PDF？**
1. 將本資料夾中的 `.html` 檔案拖曳進您的 Chrome 或 Edge 瀏覽器中開啟。
2. 按下 `Ctrl + P` (或右鍵選擇「列印」)。
3. 印表機選擇為 **「另存為 PDF (Save as PDF)」**。
4. 在「更多設定」中，**請務必勾選「背景圖形 (Background graphics)」**，邊界設為「預設」或「無」。
5. 按下儲存，即可獲得可直接寄送給客戶的專業 PDF。
